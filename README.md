# Full-Stack-Authentication-Dashboard
This is my project for a website that rewards users for viewing ads, logging in, and providing a database and admin panel. The rewards are in cryptocurrency (USDT), and the admin panel allows Admins to confirm withdrawals. It also features high levels of security against bots and multiple accounts.
